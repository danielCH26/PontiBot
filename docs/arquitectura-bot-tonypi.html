Arquitectura · TonyPi · Solución de voz

El PC piensa, el robot ejecuta

Las llamadas a la API, el LLM y el audio (micrófono y bocina) viven en el PC del usuario. El robot TonyPi solo recibe órdenes por MCP y las ejecuta con su repo interno, a través de JSON-RPC.

Reparto

Dónde corre cada cosa

  • En el PC: micrófono, bocina, ASR/TTS, LLM y todas las llamadas a la API.
  • El robot no hace nada inteligente: recibe la orden y la ejecuta con su repo interno.
  • El MCP server es el único puente: expone las 26 herramientas del robot como tools del LLM.

Restricciones

Por qué el MCP server vive en el PC

  • Raspbian Buster trae Python 3.7; el SDK mcp exige 3.10 o superior.
  • El robot no necesita internet: el PC es el único que sale a la red, así que se elimina el 403 de NVIDIA en el robot.
  • El audio va por el auricular BT del PC (PulseAudio), no por el altavoz del robot.

Rutas

Puertos y modelos

  • :9030 JSON-RPC 2.0 — órdenes del MCP al robot (ida y vuelta con el resultado).
  • :8080 snapshot JPEG — la cámara alimenta la visión del modelo.
  • LLM nemotron-3.5-bolt-e4b; ASR local con whisper.cpp (el catálogo NVIDIA de esta clave no trae ASR).
